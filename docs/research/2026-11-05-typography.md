# 全站字体可读性 · 2026-11-05

## 问题与依据

旧版导航、分类、日期、按钮、来源说明及部分项目正文大量使用 10–13px。只修改 body 字号无法覆盖页面和组件的具体规则。此次在最终加载的 site-polish.css 中统一语义字号，并调整容器换行和间距。

- [GOV.UK type scale](https://design-system.service.gov.uk/styles/type-scale/)：当前 v6 正文在大、小屏均为 19px，辅助文字为 16px；使用相对单位。手机屏幕窄不意味着正文必须更小。
- [NHS typography](https://service-manual.nhs.uk/design-system/styles/typography)：正文采用桌面 19px、手机 16px；小字号仅用于次要信息。不同体系的数值可以不同，关键是阅读层级与实际内容。
- [WCAG 2.2 resize text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html) 与 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：没有“文字必须至少 16px”的统一规定；要求关注文字放大、重排、对比度以及用户改变文字间距后的内容可用性。文字间距成功准则的测试值不等于所有网站必须采用的默认样式。
- [W3C 中文排版需求](https://www.w3.org/TR/clreq/)：中文行间留白的参考支持较宽松的阅读行距；此文是排版参考，不是本站已通过无障碍认证的依据。

## 本站采用的尺度

以下是默认根字号 16px 时的 CSS 像素值，是结合现有简洁排印风格的设计选择，并非照搬某一标准。

| 用途 | 字号 | 行高 / 处理 |
| --- | --- | --- |
| 项目正文、工具摘要、指南、弹窗说明、提示词输入与输出 | 18px | 1.8 |
| 导航、按钮、表单标签、来源链接、首页作品说明 | 16px | 1.6–1.75 |
| 日期、编号、分类、来源脚注、页脚 | 15px | 通常 1.7 |
| 导语、FAQ 问题 | 20px | 1.6 |
| 卡片和步骤标题 | 20–24px | 随视口调整 |
| 内容分节标题 | 24–32px | 随视口调整 |
| 工具箱、指南页面标题 | 32–48px | 随视口调整 |
| 首页作品名称 | 32–56px | 1.2 |
| 项目详情主标题 | 44–100px | 1.1 |

html 保留 100% 根字号，正文、操作和辅助文字使用 rem。标题使用带 rem 上下限的 clamp。图标、品牌图形和截图内文字不属于正文尺度；没有修改原有扫描线签名。

同步修改：作品说明与源码链接可换行；导航行高由内容撑开并允许换行；筛选和操作区可换行；流程、能力、事实和提示词表单按可用宽度重排；代码展示可换行；手机阅读进度可换行；对工具弹窗内更高特异度的旧字号单独覆盖。

## 验证范围

- 本地构建与静态检查：13 个 HTML、194 个本地引用、6 个项目、32 款工具（16 款精选数据）。
- 浏览器 320px 宽度检查：首页、工具箱、3 篇指南、6 个项目详情。可见 HTML 文字最低 15px，导航 16px，无页面横向溢出。此 DOM 检查不分析图片内文字或 SVG。
- 桌面 1280px 检查：首页、工具箱、写作指南及六个项目详情；平板 768px 抽查首页、工具箱、研究指南、elselife；390px 检查首页作品区。
- 动态内容：工具搜索、工具详情弹窗及 Escape 关闭、工具筛选说明展开、elselife FAQ 展开、写作指南提示词输入与实时输出。弹窗来源链接 16px、脚注 15px；提示词输入框 18px。测试输入已清除。
- 独立临时 QA 副本分别覆写根字号为 200%，或覆写 line-height:1.5、letter-spacing:.12em、word-spacing:.16em、段落下间距 2em。在 1280px 和 320px 下检查首页、工具箱、写作指南与 codegen 详情，未见页面横向溢出；并修正字间距增加时导航不换行的问题。
- 根字号 200% 是字体偏好模拟，不等同于浏览器实际页面缩放 200%；以上为针对本次修改的检查，不是完整 WCAG 审计。临时 QA 页面不发布。

## 维护

字体 token 集中于 site-polish.css；新增组件必须使用对应层级，避免再写 10–13px 的内容小字。修改后运行生成器刷新资源哈希，保持所有内容页最后加载共享样式层。
