# Final design direction

The final user constraint is restrained experimental futurism, with no conspicuous abstract 3D object. Earlier collage, spatial dock and sculpture prototypes are rejected research, not the final design specification.

The implementation uses a compact typographic opening, offset text alignment, an asymmetric six-project gallery, cold grey surfaces and quiet interaction feedback. Real project information provides the focus. Existing tool search, favorites and practical guides remain available.

References consulted in the research phase include Rauno's craft essays (https://rauno.me/craft/depth and https://rauno.me/craft/interaction-design), Apple Materials (https://developer.apple.com/design/human-interface-guidelines/materials), and official portfolios documented in the earlier research file. Their principles were examined, but the user's later rejection of interface-like composition and 3D overrides any earlier proposed translation of them. These are references, not copied code or assets.

The static architecture already supports the desired layout and behavior. No framework migration, remote font service or 3D dependency is introduced. Future design prompts should explicitly say: restrained, experimental through composition; real work first; no abstract hero object, exaggerated typography, saturated collage, floating dashboard or scroll hijacking.
