# Sumtez Studio Implementation Plan

> **For agentic workers:** use executing-plans for the main implementation and bounded parallel agents for tool library and independent review.

**Goal:** 完成统一、有辨识度、响应迅速的个人作品集并验证发布。

**Architecture:** 静态 HTML 负责可直接读取的内容；CSS 负责视觉系统；JS 仅增强工具、进度和动效。产品数据保持 content.js 单一来源，生成器生成产品介绍与首页作品。

**Tech Stack:** HTML, CSS, native JavaScript, Node build script, Sites.

**Spec:** ../specs/2026-10-23-studio-design.md

## Global Constraints
- 保留真实项目、原有路由与浏览器存储键；不修改 production-site。
- 不增加框架依赖、外部字体请求或滚动劫持。
- 主源码 personal-site/dist；发布镜像 sumtez-public。

## Review Focus
- 无 JavaScript：作品与导航仍可用。
- 390px / 320px：无横向溢出，输入不触发缩放。
- 键盘：所有可操作项可访问，弹窗关闭后焦点恢复。
- 动效偏好：减少动态、暂停、切到后台均停止装饰动画。
- 内容生成：再次运行生成器不回退样式和版本号。
