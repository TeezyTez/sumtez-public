# Sumtez — 好奇心的作品集

## Intent
把现有的个人主页、6 个真实项目、32 款 AI 工具与 3 篇实践指南组织为有个人辨识度的作品集。用户授权全面优化、探索多种方向并追求高质量；视觉与技术选择由本轮执行者提出并落地。

## Direction
比较了轻量编辑式作品集、密集实验室界面、重沉浸式工作室三个方向。本轮选择编辑式作品集，加入克制的实验图形：适合中文内容和真实项目，也能在手机上完整阅读。保留“把好奇心，做成作品”的定位。

暖纸 #f5f3ec、墨色 #242b26、森林绿 #29493d、朱红 #c64b31；中文衬线用于主标题，系统无衬线用于正文，等宽用于少量数据。桌面内容宽 1184px；小屏边距 24px。标题、段落与控件使用流体尺寸。通过留白、图文比例与线条建立层级。

## Experience
- 首页以个人定位和原创 SVG 轨道图形开场；图形轻微响应指针，提供暂停动效控制。
- 真实 ainovel 截图作为重点作品；其他项目用明确标注的流程概念图表达各自问题，不伪装为产品截图。
- 首页工具默认展示 6 款，筛选后完整匹配 16 款精选；32 款目录保留所有筛选、收藏、来源详情。
- 三篇指南继续提供提示词填写、复制、步骤进度。产品页与指南共享视觉规范。
- 导航、按钮、卡片有清晰 hover、focus、active；滚动只做渐进增强，无滚动劫持。减少动态效果时关闭非必要动画。无 JavaScript 时作品正文和链接可用。

## Constraints
保留所有真实内容、原型/MVP/研究阶段、仓库链接、旧路由、浏览器存储键。不得虚构上线、购买、客户或成绩。不得公开凭据和私有样本。使用现有 buildless HTML/CSS/JS，暂不迁移框架。Sites personal-site 为权威源码，sumtez-public 为 GitHub 发布副本。production-site 是过时且有本地修改的副本，不修改。

## Quality
桌面和 390px 手机视觉 QA；全部产品页面、3 篇指南、工具搜索/筛选/收藏/详情/空状态、键盘和减少动态效果检查；脚本语法、站内链接、构建可重复性。发布到已有 Sites，保留公开 audience。记录参考、决策和验证结果。
