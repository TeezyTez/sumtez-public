# Experimental entry

The user now explicitly prioritizes a cool, avant-garde, experimental homepage over showing every project. Prior constraints still apply: little explanatory copy, digital art rather than a dashboard, no unrelated 3D object. They have authorized multiple visual attempts and comprehensive implementation.

Approaches considered: a large project preview still lets another UI dominate; the six-project typographic index still reads as a conventional portfolio. The selected implementation direction is a full-viewport, two-dimensional interactive type poster. This is an implementation decision under the user's open design brief, not a claim that they selected a specific mockup.

Composition: cropped oversized Sumtez letterforms, sharp black and paper-white contrast, a narrow vertical optical cut with slight violet separation. The cut moves slowly at rest and responds locally to pointer movement and press. A reversible negative treatment changes polarity. Mobile uses two stacked syllables instead of shrinking the entire artwork.

Homepage copy is limited to identity, useful navigation and a small interaction hint. Six projects, tool preview, notes and contact remain reachable on work.html; tools.html remains the full catalogue. Real content and existing tool behavior remain intact.

The artwork is native 2D canvas, with readable HTML fallback, no added dependency, no network assets. Pause, reduced-motion, keyboard-accessible polarity control, page-visibility suspension, capped pixel ratio and frame rate are required. Navigation is ordinary links and remains usable if animation fails or JavaScript is disabled.
