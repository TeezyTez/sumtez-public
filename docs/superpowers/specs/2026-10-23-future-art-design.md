# Sumtez — restrained experimental portfolio

## User direction, in order
The user rejected the conventional warm portfolio, then rejected loud editorial collage. They requested experimental futurism without exaggeration, and more digital art with less interface. They subsequently explicitly rejected the abstract 3D object. **That latest correction overrides the sculpture direction.**

## Final implementation
No homepage sculpture, WebGL, shape controls, or full-height decorative stage. A compact asymmetric typographic opening introduces Sumtez and leads directly into the six real projects. Cold grey, modest sans-serif Chinese typography, thin rules, offset baselines and varied project proportions supply the visual structure. No floating app panels or widget dock.

The six projects form a static asymmetric gallery. ainovel uses its real screenshot; other project covers are clearly labelled conceptual. Tools and practical guides retain functionality and share the neutral palette. All controls remain normal keyboard-accessible HTML.

## Motion and performance
Only brief link feedback and one-time content reveals. Reduced motion disables reveals. No scroll hijacking, continuous decorative animation or heavy rendering dependency. The opening and project links are readable without scripting.

## Implementation
Preserve static architecture, source data, routes and the existing audience. Shared theme, gallery and interior CSS are separate. The rejected sculpture implementation remains only in the local QA experiment folder; it is excluded from the deployed assets. The social preview and favicon are also replaced.

## Completion checks
Check desktop/mobile screenshots, navigation, tools filtering/favorites/dialog, guide prompt/progress, no horizontal overflow at 320/390/768/desktop. Check generator idempotence, JavaScript syntax, local links and independent review before publication.
